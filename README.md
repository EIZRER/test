# Live Event Map

A modern web application for displaying and filtering live events with an interactive map interface.

## Features

- Horizontally scrollable event cards
- Category-based filtering
- Responsive design
- Interactive map integration
- Modern UI with Tailwind CSS

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- Vite
- React Icons

### Backend
- Node.js
- Express
- TypeScript
- CORS

## Setup

1. Clone the repository:
```bash
git clone <repository-url>
cd Live_Event_map
```

2. Install dependencies:

For the frontend:
```bash
cd frontend
npm install
```

For the backend:
```bash
cd backend
npm install
```

3. Start the development servers:

Backend (in the backend directory):
```bash
npm run dev
```

Frontend (in the frontend directory):
```bash
npm run dev
```

The frontend will be available at `http://localhost:5173` and the backend at `http://localhost:3001`.
